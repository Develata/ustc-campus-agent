# USTC Campus Agent 作品简介

一〇七杯智能体赛道 · 校园服务与个人学习规划

USTC Campus Agent 是面向科大学生的插件化校园智能体。它把办事信息、校历变化、课程建议与个人日历组织到一个对话入口，让用户从“找到答案”继续到“确认并保存安排”。模型负责理解任务与表达建议，Rust 服务核心负责检查参数、来源、权限和实际执行结果。本项目是学生竞赛作品，非学校官方服务。

## 解决的问题

校园信息分散在通知、办事指南、课程材料和个人记录中。学生不仅需要知道“去哪办、怎么办”，还需要判断资料是否有效、自己的课程是否冲突，以及提醒是否真正保存。纯聊天回答难以提供这些操作层面的保证。

本作品将来源核对、确定性课程约束和个人事项管理结合起来。回答可以回到原始资料，日期安排先显示可确认的提案，执行后保留可回读的记录，让校园任务形成完整过程。

## 核心功能

- **校园信息查询**：查看办理步骤、官方入口、资料来源和校历变更。资料工作区支持管理员审阅清单约束下的导入、查询与版本观察；固定演示资料会明确标注。
- **个人日历**：按月选日，月历中的新增、修改、删除和课程批量安排先核对提案再确认；保存完整时间与时区，重启后保留。到期事项支持站内提醒和投递回执。
- **课程推荐**：结合用户提供的课程原文、先修、学分、时间、兴趣和空闲安排，由 Rust 检查冲突并比较方案，再生成可确认的日历批次。模型的学科建议与学校规则分别说明。
- **Plugin Market**：统一管理 Skill、MCP 与组合包，完成安装、配置、检查、审阅权限和授权启用。Skill 按需读取，MCP 连接已审阅的公开只读工具；停用和版本切换会重新限制后续调用。
- **持续使用体验**：保存对话与执行进度，支持模型切换、个人根提示词、日期话题名、置顶与分组。后台配置多账号后，个人会话、日历及插件配置与授权相互隔离，无注册或邀请入口。

## 技术实现与模型调用

核心以 **Rust** 编写，采用中心服务统一管理校园资料、插件权限和执行回执。Web 与 Android 客户端承担交互，服务端承担业务规则；应用、领域与外部协议通过窄接口分离。Rust 原生编译、类型约束和无需垃圾回收的运行方式服务于性能、资源控制和长期维护目标。本机 release 程序的 100 次串行日历查询中，中位耗时为 3.35 毫秒，P95 为 4.51 毫秒（i7-12700H、WSL2 Debian 13，含连接与结果解析）。这是不含模型调用的本地接口基线，不代表并发吞吐或相对其他框架的性能优势。

真实模型测试采用 **gpt-5.6-luna**；**deepseek-v4-flash-ascend** 为可配置备选，**hy-mt2** 用于本地纯文本连接测试。服务通过 OpenAI-compatible 的 HTTPS `POST /v1/chat/completions` 发送模型标识、消息与工具定义，并处理 JSON 或 SSE 响应。密钥从服务端私有文件读取，浏览器只选择已配置模型，提交包不附私人密钥。离线 `mock` 模式无需模型网络，可复现内置校园工具流程。

## 创新点与设计参考

创新重点是校园任务的组合与可信执行：用同一个 Agent 串起资料查询、课程约束和个人安排，以包级权限和执行回执约束工具，而不是让模型直接操作全部服务。中心式设计面向多人共享公共校园资料、隔离个人状态，降低每位用户自行安装开发环境的门槛。

项目在 **2026 年 7 月**已形成插件化校园智能体与 Rust 核心的初始规划，后续参考了 DeepSeek Harness 的插件组合、工具过程展示与简洁聊天交互。DSH 主要面向开发者工作区，官方目前仍标为开发者预览版。UCA 聚焦中心式校园服务，综合已有 Rust 技术路线、资源控制、持续维护及第三方依赖和许可证管理，选择继续建设自有核心并借鉴优秀设计。DSH 采用 MIT，允许遵循许可证的二次开发；本项目的选择属于工程取舍，不是版权禁止。

## 当前交付范围

本次提供设计文档、约五分钟实际演示、Linux/WSL 可执行程序、离线 Docker 镜像及同源 Android 调试 APK。后台配置账号、来源管理和插件流程已有本地验证；Android 构建、签名、小米安装、首页与日历查询检查通过。公网多人部署、学校 SSO、完整 RAG 与多智能体协作仍待实现或验收。本次程序包采用自建合成课程资料，不纳入 iCourse 聚合评分；iCourse 仅作参考链接。源码保留的历史样例许可问题单独记录，不包装成已授权的实时课程数据。
