# 使用个人日历

从插件页打开“日历”，或在 Chat 输入区上方展开“日历事项”。月历按北京时间显示已确认事项；待确认提案单独列出。

- 点月份选择年月，用左右箭头切月，点“今天”返回当前日期。周一至周日排列，自动适配大小月和闰年。
- 点日期查看当天事项，再点“添加事项”。时间预填当天 09:00，可自行修改；选择日期本身不会写入。
- 手机月历显示日期和事项数量，完整标题、时间及操作放在下方。无日期记录从“无日期事项”进入。
- 填写标题和时间后点“生成提案”，核对内容，再点“确认执行”。修改、删除也遵循这一流程。
- 使用支持工具调用的模型，也可直接描述安排；不明确的时间应先澄清。离线模式可使用手动表单。

月历支持方向键选日、PageUp / PageDown 切月、Home / End 到一周两端。自动刷新保留选中日期、月份和未提交的表单。

提案有效期 30 分钟。版本冲突或过期后，需要核对最新事项并重新提出。网络结果不确定时，页面读取服务端记录，只允许重试原请求，避免重复写入。确认成功后选中该事项日期，方便回查；刷新和服务重启后记录仍保留。

新确认的定时事项到点投递站内提醒，可标为已读；这不是手机系统推送。选课方案的批量加入同样先提案、后确认。重复日程与外部日历同步尚未实现。

配置多人认证时，日历按登录用户隔离。未配置认证的本机预览使用演示身份，不代表学校 SSO 已接通。

实现、持久化版本及恢复边界见[日历提案契约](../contracts/calendar-proposals.md)。
