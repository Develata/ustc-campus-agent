# GitHub Pages brief

This guide is a future public-site handoff. The site is not the Dioxus application client or application runtime and must not claim official USTC status or unimplemented product behavior.

## Purpose

Build a polished public-facing project/display/download site for USTC Campus Agent only after the public-readiness gate authorizes publication.

## Content architecture

1. Hero: `USTC Campus Agent` and “面向科大学生的插件化校园智能体”.
2. Problem: campus information, planning, opportunities and procedures are fragmented.
3. Product: Plugins Market + USTC Affairs Navigator + USTC ChangeRadar + Campus Opportunity Graph + bounded Agent.
4. Demo: inspect all three package identities → open one honest journey per Plugin → inspect source/effective time → disable/re-enable independently.
5. Architecture: shared Campus Trust Kernel, independent package lifecycles, source/revision/provenance and permission boundaries.
6. Status: competition prototype; current implementation and limitations stated exactly.
7. Download: absent/disabled until a verified release exists.
8. Team/acknowledgement: no fabricated affiliation, logo, testimonial or metric.

## Design direction

- Direct, functional and restrained; no invented poetic Chinese brand.
- Apple-like hierarchy, content deference and restrained motion.
- One signature visual: a three-way projection from the shared Campus Trust Kernel into procedure, change and opportunity views.
- Avoid generic purple gradients, fake dashboards, nested-card density and inflated metrics.

## Acceptance

- responsive mobile/tablet/desktop evidence;
- Lighthouse/accessibility basic pass;
- visible keyboard focus;
- no console errors or broken internal links;
- claims match manifests, features and acceptance status;
- download controls point only to remotely verified release assets;
- `docs/acceptance/public-readiness.md` passes before publication.

## Scaffold timing

Now: keep this handoff and public-readiness contract.

Later: add the actual Pages framework, workflow, visual assets, release integration, browser QA and publication gate in one reviewed frontend slice.
