# Official-source observations and personal course input

The [bounded workspace contract](../contracts/campus-source-workspace.md) owns these
flows. They extend the local campus Agent demonstration and do not promote overall
M60 or multi-user acceptance merely because the panels exist.

In the Affairs panel, search current source observations, follow the original official
link, inspect observation time, local review status, content hash and prior revision
line differences. An administrator can fetch an exact pre-reviewed official URL,
import its public text, and record a separate content review. Sources need genuine
operator-configured evidence; an empty manifest honestly shows no configured sources.
The Agent can search and fetch approved public source IDs through bounded read tools.
A fetched page is an observation, not an official interpretation or publication.

In the Course panel, enter real source excerpts, codes, titles, credit units,
prerequisites, interests and exact meeting dates. Set weekly availability and consent
only to the current request. Compare reasons and exclusions, then preview exact
calendar additions and confirm them separately in Calendar. Missing dates are never
invented. The Chat equivalent requires the user's current consent control and a small
course payload within the existing tool budget. No profile is saved and no iCourse
ratings are retrieved by this path.

Verification bindings: `S1-LOCAL-OBS-001` and `O1-PERSONAL-PLAN-001`, with commands in
the owning contract. Real source acquisition, browser and calendar acceptance are
reported separately from controlled domain tests.
