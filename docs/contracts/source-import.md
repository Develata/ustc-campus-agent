# Source import contract

## USTC catalog

Preferred order:

1. official API or approved application/service account;
2. PlatformOperator imports an approved read-only snapshot with hash and revision metadata;
3. user imports non-sensitive opening-list fixture for their own planning;
4. browser/device relay only after a separate risk review.

Central platform storage of a user's raw USTC password is forbidden.

## iCourse

Default mode is link-out-only. Do not fetch, aggregate, cache, or summarize review content unless explicit permission and a data-use contract exist.

## Provenance

Material facts must carry source id, source authority, retrieval/import time, effective time where available, hash/revision, and conflict status.
