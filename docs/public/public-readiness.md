# Public repository readiness

This repository may become public later. Public visibility requires an explicit decision and the following gate:

- [ ] license selected and `LICENSE.md` updated;
- [ ] secret scan and Git history audit completed;
- [ ] private fixtures removed or replaced with approved anonymized examples;
- [ ] USTC non-official disclaimer visible in README, Pages, and app UI;
- [ ] iCourse and USTC catalog data-use permissions documented;
- [ ] no real student personal data in issues, docs, screenshots, logs, or artifacts;
- [ ] release/download surface verified or hidden;
- [ ] GitHub Pages copy contains no fabricated metrics, testimonials, logos, or download links;
- [ ] Gitea mirror policy updated for public source and private backups.
