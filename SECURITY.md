# Security Policy

## Current status

USTC Campus Agent is a student competition project under private development. Do not use it for production access to USTC services.

## Sensitive data rules

Never commit:

- USTC unified identity credentials, CAS tickets, cookies, MFA material, or screenshots exposing them;
- API keys, GitHub tokens, model provider keys, private keys, or `.env` files;
- real student academic snapshots, grades, ranking, phone numbers, or identifying course-plan exports;
- raw iCourse review corpora unless explicit permission and a data contract exist.

## Reporting

For now, report security issues privately to repository maintainers. If the repository becomes public, this file must be updated with a real contact and disclosure policy.
