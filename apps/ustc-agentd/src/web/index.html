      关于这个助手

      USTC Campus Agent 是学生竞赛项目，非中国科学技术大学官方服务。当前使用本机演示会话，不连接学校账号。

      对话保存在当前服务端，刷新后可从历史对话恢复；新对话不会删除旧对话。删除只从历史列表移除，后台仍保留记录，也不会撤销已执行的日历操作或删除课程档案。课程档案的创建与使用始终需要你的明确同意。

      Enter 发送，Shift + Enter 换行。回答由 AI 生成，办理与选课请核对官方来源。
